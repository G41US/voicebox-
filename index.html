Use it on a call (Windows, one-time setup)

  1. Install the free VB-CABLE virtual audio driver from vb-audio.com/Cable, then restart the PC.
  2. Open this file in Chrome, press Start and allow the microphone.
  3. Under Send changed voice to, pick CABLE Input.
  4. In WhatsApp Desktop (Settings → Audio / during a call → ⋯ → microphone), Discord (Voice & Video → Input Device) or Zoom (Audio → Microphone), choose CABLE Output as the microphone.
  5. Call someone and pick a voice. You can switch voices mid-call.

Wear earphones if you turn on "Hear myself", or the speakers will feed back into the mic. Keep this tab open during the call.
